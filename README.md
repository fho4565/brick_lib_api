Brick Lib API是Brick Lib的一部分，旨在提供供开发者进行跨平台，版本开发的最基本功能

Brick Lib API提供了以下功能

1. 新增了支持事件注册、触发和取消的通用事件API。
2. 添加了通用注册 API，支持原版注册表和 Brick Lib 的额外注册表（注：低版本在兼容性更新后会包含更高版本的注册表，但这些只是占位符，注册对象类型为 Object！）。
3. 新增通用网络API，支持服务器端向客户端及游戏内常规网络包的登录包。它还允许两端之间直接发送字符串，并通过事件监控发送/接收。
4. 添加了通用配置文件API，采用Forge风格的配置文件进行配置管理。
5. 支持通用数据生成器、更新检查器和客户端命令。
6. 支持自定义 JSON 函数，允许在 JSON 和返回值内调用注册处理程序。
7. 新增 ResourceID 类，用于部分替代 ResourceLocation 类
